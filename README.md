# Manufacturing-Operations-Analytics-built-entirely-in-MySQL.
I designed a relational database simulating a global manufacturing environment  and perform different SQL query operations
across 3 plants and 5 product lines, and developed 11 analytical queries covering:

✅ Multi-table JOINs
✅ CTEs & Chained CTEs
✅ Window Functions (RANK, Running Totals)
✅ CASE Logic for performance classification
✅ OEE (Overall Equipment Effectiveness) Scorecard
✅ Defect Rate & Downtime Analysis

This project reflects the kind of data challenges operations and manufacturing teams face every day — production fulfillment tracking, quality control, and plant performance benchmarking.
